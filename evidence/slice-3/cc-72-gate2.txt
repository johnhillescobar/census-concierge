Pass 1 findings:

1. Dataset/year policy is gated on consecutive() -- a dense span
   (max-min+1 == n, n>=2). Any hole in the years list skips the ACS1 probe
   and skips destagger. fetch then issues every requested ACS5 year, including
   overlapping end years. Example: [2018,2019,2021,2022] is not consecutive,
   so 2020 already absent does not select ACS1 and does not destagger.

2. plan_years destagger branch (consecutive, dataset != acs1, not acs1_ok)
   never calls _drop_unpublished. Unpublished ACS5 years in the requested
   list can be attempted and fail HTTP instead of being omitted with
   unpublished_vintage.

3. FetchDataTool._acs1_ok treats probe timeout, HTTPError, non-200, or
   unparseable payload as geography ineligible. plan_years then destaggers
   ACS5 and sets acs1_ineligible=True. The user-facing warning text says
   ACS1 is not published for this geography (places of 65,000+), which is
   false when the probe failed for transport or 5xx.

4. FetchDataTool.allow_overlapping_acs5 is a constructor bool copied from
   ExecutionRecord at default_tools() time. AskRequest is still question-only;
   POST /ask never sets the flag. The override path exists only if a caller
   builds the tool itself.

5. _tool_content zips omitted_years with omission_reasons using strict=False,
   so a length mismatch is truncated in the model-visible summary rather than
   raising.

6. Race: none found. CensusURL is immutable; fan-out shares a template and
   a bound semaphore; probe is synchronous before gather. Redaction: with_dataset
   rewrites the redacted path; with_key is only at _get; probe exceptions are
   discarded; legs store str(CensusURL). No new unredacted URL path.

7. Tests: new vintages/fetch assertions bind attempted years, dataset path,
   and HTTP URLs seen -- they can fail. Guard tests plant FetchDataResult
   flags rather than driving fetch; they can still fail on evaluate() codes.
   No same-table-for-any-input fake. No prompt-wording asserts.
