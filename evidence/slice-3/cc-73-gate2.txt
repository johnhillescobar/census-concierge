Pass 1 findings:

1. Versus resolution keeps only specs[0] per side and sets compare=True.
   ResolveGeographyTool._arun splits on versus / compared to / compare…to, then
   appends hit.specs[0] from each side and drops the rest. guards.ambiguous_place
   returns None whenever geo_status.compare is set. An ambiguous left or right
   side (Springfield vs Illinois) is fetched as the ranked first match with no
   leftover specs and no warning. Silent geography substitution.

2. Named-county parent listing also ranks and keeps one row. "every tract in
   Wayne County" with no state lists counties (state:* if needed),
   rank_matches(filter_rows(...))[0], and emits one tract:* spec. Wayne NC is
   discarded. geographies length is 1, so ambiguous_place cannot fire.
   test_tracts_in_wayne_without_a_state_pick_michigan locks this in.

3. Year/geo fan-out collides in the year buckets. _pack unique_years()s
   attempted/succeeded/failed from legs. Two geos times one year that fails on
   only one side puts that year in both succeeded_years and failed_years.
   ok = any(leg.ok), so a one-sided comparison is a successful fetch. Failed
   URL is kept on the leg. Consumers of the year lists cannot see which
   geography failed; only legs[].for_spec can.

4. ACS1 204/404 on any cartesian leg retries the entire plan as ACS5 and
   discards the first gather, including legs that already returned 200.
   _acs1_ok still probes only the built URL (build_url's last_geography =
   specs[0]), then fetch rewrites for/in for every compare spec.

5. Top-level AskResponse.geoid uses record.geography (always geographies[0])
   as fallback in _response_geoid, which returns fallback whenever it is
   non-empty. A two-area comparison therefore names the first side's AFFGEOID
   even when rows contain two GEO_IDs. Contract text says empty when many
   areas are returned. Wildcard specs empty geoid and escaped this; compare
   specs carry geoids and do not.

Pass 1 hunted items that were not present (nothing):

- Dropped URLs: nothing. Failed compare legs keep the redacted URL on
  RequestLeg.url and on urls[].
- Wildcard expanded into N requests: nothing. A :* spec is one GET; ask.py
  only passes last_geographies when compare is set, so a tract:* resolve does
  not fan out listed tracts.
- Comparison legs tripping ambiguous_place as a false positive of two
  executable specs: nothing. The compare flag skips that guard for the
  two-leg case. The defect is the opposite (Pass 1 #1): real ambiguity on a
  side is also skipped.
- Key leakage: nothing. with_geography rewrites self._redacted; with_key is
  only at _get; failed-leg detail uses redact_text; list_census_names
  exception text is str(CensusURL).
- Budget-busting: nothing from reading the diff. Machines report largest
  file LOC 400 on the cap; no ceiling raised.
- Race: nothing. CensusURL is immutable; fan-out shares a template and a
  bound semaphore (MAX_IN_FLIGHT 5).
