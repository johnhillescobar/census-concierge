## Pass 1 — generic bugs (diff only, no intent)

Cold-read of origin/main...HEAD as code. No ticket text as spec.

Control flow (plan_years)
- Empty years still return VintagePlan with default acs1_ineligible=False.
- Destagger branch is unchanged: series and dataset != "acs1" and
  acs1_ok is not True; flag is `acs1_ok is False`.
- Else branch previously left acs1_ineligible at the dataclass default
  (False). It now sets
  `acs1_ok is False and use == "acs5" and not allow_overlapping_acs5`.
- `use` is "acs1" when series or dataset == "acs1", else the incoming
  dataset. An ACS1 plan with acs1_ok=False does not set the flag here;
  a later ACS5 replan can.
- Cap rebuild copies plan.acs1_ineligible. apply_variable_plan is not
  in this diff and already copies the field.

Default change
- acs1_ok default False → None. Destagger still runs on None
  (`is not True`). Flag is False unless acs1_ok is exactly False.
  Unprobed / omitted-arg destagger no longer inherits ineligible=True.
  Fetch always passes acs1_ok; production first plan is None unless a
  series probe ran.

Callers
- Only fetch.py calls plan_years. First plan passes probed-or-None.
  ACS1 204/404 replan passes dataset="acs5", acs1_ok=False. That replan
  is how a non-series year list reaches the new else-branch True.
- allow_overlapping_acs5=True forces series False, so the else branch
  suppresses the flag (same outcome as the existing overlapping
  override test on consecutive years).

Missed cases checked
- Single year, acs1_ok=False, dataset=acs5: else, flag True.
- Gapped non-series (e.g. 2019+2022), acs1_ok=False, dataset=acs5:
  else, flag True. Same predicate as the single-year path; no extra
  branch. No dedicated fetch test for that list shape.
- dataset=acs1, acs1_ok=False: else, use=acs1, flag False.
- acs1_ok=None or True on else: flag False.
- First fetch plan for a non-series ACS5 template never probes, so
  acs1_ok stays None and the new True path is not taken until a 204/404
  ACS1 replan. That is existing fetch control flow, not this diff.

Incorrect control flow
- nothing. Destagger flag formula unchanged. Else-branch True only when
  known-ineligible, the plan is ACS5, and overlapping override is off.

Pass 1 findings: nothing.
