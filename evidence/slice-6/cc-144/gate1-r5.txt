PRODUCT DEFECT FOUND (scripts/ not changed)

Low. _fields() calls reply.get(), so a reply that is valid JSON but not an object raises AttributeError.
_write() catches TypeError (what the old api(...)["fields"] raised) but not AttributeError. If such a reply
arrives after the PUT, --apply ends in a traceback in place of its FAILED line. The run stays stopped: the
FAILED file written before the PUT remains. Real Jira has not been seen to send such a reply.
