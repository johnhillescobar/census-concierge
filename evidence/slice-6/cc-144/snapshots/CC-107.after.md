## Context

Split from CC-43. After a result exists, a follow-up that only changes the place keeps the table, years, dataset and geography level and swaps the geography. Built on CC-43 (prior plan reaches the loop) and measured with CC-42.

## Acceptance Criteria

- [ ] After "median household income in Ohio", the follow-up "what about Texas?" produces a final plan with the same `table_id`, `years` and `dataset`, and the Texas state GEOID.

- [ ] The geography level is carried over: after a question at county or tract level, a swap to another place is fetched at the same `for=` level, unless the follow-up names a different one. If the table is not published at that level for the new place, the response is a warning with the nearest available level and candidates, never a silent change of level.

- [ ] MOE is fetched for the new geography, and the full Census URL renders, including when the fetch fails. The response keeps the GEOID, the universe and alternative tables.

- [ ] The new turn stores its own `plan`; the prior turn is not modified.

- [ ] No regex or keyword table detects "swap" phrasing; the model emits the new plan through the existing tools and code only validates it.

- [ ] Case-level rate over the 6 swap cases in the CC-42 set at `--repeat 3` is above the CC-42 baseline by more than one case's worth at case level (a case passes when the final plan is right in at least 2 of 3 repeats); the number is quoted in the PR next to the baseline.

- [ ] `make demo --repeat 3` single-turn long_tail answered_rate, at the same `--repeat` and the geography-level scorer, is no more than 3 points below the 0.742 baseline (>= 0.712) and no more than 3 points below this ticket's own pre-run; both runs are reported. Same-code runs vary by about 2 points (0.725 vs 0.742), so one run is not a verdict.

- [ ] `make check` passes with `budgets.toml` unchanged.

## Test cases

- Happy: a geography-swap follow-up changes only geography while retaining table, variables, dataset, years, and level.

- Edge: a county- or tract-level prior plan swaps geography while preserving that non-place level.

- Novel: a metadata-valid geography absent from visible examples is resolved through the existing tools.

- Regression: the stored prior turn and its original result remain unchanged after refinement.

- Failure: an incompatible or unresolved swap returns candidates and a warning without blocking or silently changing level.
