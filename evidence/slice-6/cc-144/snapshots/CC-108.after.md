## Acceptance Criteria

- [ ] After "population of Chicago", the follow-up "add median income" returns the prior table and the new table for the same GEOID, each with its own full Census URL, MOE and universe.

- [ ] The new table is fetched at the same geography level as the prior one. If it is not published at that level, the response is a warning with the nearest available level, never a silent change of level.

- [ ] The universe difference between the two tables is visible in the response (the two `universe` values are both present). The response keeps the GEOID and alternative tables for the new measure.

- [ ] The prior table's result is unchanged and still restorable from the stored turn.

- [ ] No regex or keyword table detects "add" phrasing; the model emits the new plan through the existing tools and code only validates it.

- [ ] Case-level rate over the 6 variable-addition cases in the CC-42 set at `--repeat 3` is above the CC-42 baseline by more than one case's worth at case level (a case passes when the final plan is right in at least 2 of 3 repeats); the number is quoted in the PR next to the baseline.

- [ ] `make demo --repeat 3` single-turn long_tail answered_rate, at the same `--repeat` and the geography-level scorer, is no more than 3 points below the 0.742 baseline (>= 0.712) and no more than 3 points below this ticket's own pre-run; both runs are reported. Same-code runs vary by about 2 points (0.725 vs 0.742), so one run is not a verdict.

- [ ] `make check` passes with `budgets.toml` unchanged.

## Test cases

- Happy: a variable-addition follow-up preserves the original result leg and adds the requested table as a separate leg with its own URL, MOE, and universe.

- Edge: an added measure with a different universe remains separate and is not joined or described as directly comparable.

- Novel: a table absent from visible examples is found through retrieval and selector rather than a phrase rule.

- Regression: the original leg, chart, table, and export remain intact when the additional leg is added.

- Failure: an unavailable or incompatible added measure is warned and never fabricated or silently joined.
