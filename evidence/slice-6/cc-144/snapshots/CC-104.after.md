AC7. AC9. A state supplied from model knowledge is recorded as inferred rather than question-given and cannot suppress ambiguity for a place name that the user did not qualify with a state. Model-owned intent (owner alignment 2026-11-08)
Once the model supplies structured intent, deterministic resolution, validation, URL construction, fetch, computation and recovery use that intent, authoritative Census metadata and execution artifacts. They must not reinterpret original question wording, paraphrases or reconstructed English commands. This prohibits regexes, keyword/substring matching and equivalent semantic heuristics, including legacy fallbacks. Missing or invalid intent returns structured feedback for bounded model repair. No missing, late or uncertain report activates a prose parser.
Original text belongs only in model interpretation, semantic retrieval/reranking, storage, display and audit; deterministic execution inputs must not expose it indirectly through a broad record. Exact identifier parsing, metadata lookup, matching an already-identified entity to NAME candidates, URL encoding and arithmetic remain legitimate. Name lookup must not infer scope, parents or level from a sentence.
Keep requested intent separate from executed plans and explicit defaults/assumptions/deviations. Preserve grounded candidates, the editable plan strip and the level-incomplete no-URL refusal; no blocking question, fabricated data or unrelated national/total-cell fallback. Unsupported availability is distinct from misunderstanding. One existing loop, no second planner or validator stack, no budget raise.

Regression analysis — 2026-11-13

The decrease against same-window main is approximately 25 trials. Table-choice drift was also present on main (58 branch misses versus 50 candidate misses on long_tail) and is treated as day-level model noise, not as the explanation for the code-caused decrease below.

Cause 1 — split report overrides a correct answer

Status: fixed locally. Affected: q28 and q32. For plain state questions, the beside-call reported listing=true and level=county. Recovery replaced the loop's correct state fetch with a county list after the prior two-parent gate was relaxed for single-parent listings. The local fix gives precedence to a successful state fetch over a same-state single-parent report while retaining all five repair conditions in AC6/TC7. Evidence: evidence/slice-6/cc-104/gate1-e2e-single-parent.txt. The fix was committed locally but had not been pushed when this analysis was recorded.

Cause 2 — refused first call remains unmet

Status: not fixed. Affected: q19, q32 repeats 2 and 3, and q03. A single-place request may first produce a listing-shaped call with an invalid level such as us or place, be refused, and then be corrected successfully. The stale refused level currently remains unmet and can produce geography_level_mismatch or unnecessary repair. AC7 and TC8-TC9 distinguish a superseded invalid execution attempt from a genuinely requested level that remains unserved.

Cause 3 — report invents years or products

Status: not fixed; highest severity. Affected: t05, t10 and q32. A report-supplied year can cause data to be fetched for one vintage while the rendered URL names another; a report-supplied dataset can also hide an overlapping_vintage warning. This is a silent wrong-answer risk that the demo scorer does not currently detect. AC8 and TC10-TC11 require the already-built fetch to remain authoritative and report disagreement to become a warning.

Cause 4 — model supplies an unstated state

Status: not fixed. Affected: t05. Existing places guidance can cause the model to choose a state for an unqualified place, suppressing the expected ambiguity warning. AC9 and TC12 use the structured given/inferred distinction so model knowledge cannot masquerade as user-supplied geography.

Cause 5 — no national fallback

Status: by design. Affected: t01. A comparison that names no place now returns no URL instead of defaulting to a national fetch. AC10 and TC13 preserve this approved behavior and prevent it from being treated as a regression fix.
